How I Built This

A log of the AI prompts used to generate this entire website, per the assignment requirements.

Prompt 1: "i need to build a website for my class this is the exact assignment: Requirements: 1. You will build a website completely using one of the AI autocoding tools... I was thinking of asking AI to create me a dynamic website..."
Result: The AI analyzed the assignment and proposed several project ideas. It created an initial implementation plan outlining the steps: build the app, document the prompts, and deploy it publicly.
Prompt 2: "i want to create an interactive website to help me study for my final exam for data structures and algorithms. I can provide a file of our final review"
Result: The AI updated the implementation plan to specifically build a Data Structures and Algorithms study tool and requested the review file to extract custom study materials.
Prompt 3: "i want a section for flashcards, multiple choice, and visuals of the structures. I do have a github account."
Result: The AI generated the core codebase (`index.html`, `style.css`, `script.js`) featuring a dark-mode design with three functional tabs: Flashcards, an interactive Multiple Choice quiz, and a Visuals section using Mermaid.js.
Prompt 4: "i want it to be more visually pleasing. for the multiple choice questions i want 3 categories easy moderate and intermediate. include ALL information from the review. including coding examples. also change the name from DSA Mastery to 'DSA Final Review'. i want this website to look advanced and help me be well over prepared for the final. also include visuals for algorithms not just structures."
Result: The AI aggressively overhauled the entire codebase with a premium glassmorphism design. It rewrote the JavaScript to include massive arrays of categorized quiz questions and flashcards covering Sorting, DP, Trees, and Graphs, including code snippets and algorithmic flowcharts.
Prompt 5: "I want a computer science theme that matches the material. Write a CSS snippet for a subtle 'Blueprint Grid' background using background-image: linear-gradient. It should have thin, dark-grey lines on a near-black background to look like a digital engineering grid. Create a CSS/JS component that looks like a terminal window..."
Result: Antigravity overhauled the aesthetic, injecting a technical "Computer Science" theme. It created a dark-mode blueprint grid, styled the quiz containers to mimic terminal windows complete with macOS-style window controls, and utilized system fonts to emphasize the digital engineering feel.
Prompt 6: "Create a dashboard UI where each DSA topic has a circular progress ring showing 'Mastery %' based on correct answers, and a 'Heat Map' that turns from red to green as I complete more questions in that category. Write a JavaScript function that takes a JSON object of 50+ DSA questions and randomly selects a 'Mock Exam' of 20 questions..."
Result: The AI successfully generated a comprehensive Dashboard UI with dynamic Mastery progress rings and a Heat Map. It built out a mock exam generator in JavaScript to pull randomly from a database of categorized questions, ensuring full topic coverage, and added a 'Study Later' feature that uses Local Storage to persist weak points.
Prompt 7: "Create a CSS 'Skeleton Loader' animation for my cards. While the Mermaid diagrams are rendering, show a pulsing gray placeholder so the page doesn't look empty or broken. Write CSS for the div that contains my Mermaid diagrams. Give it a slightly darker, recessed background (#030712), padding of 20px, and overflow: hidden. Add a 'Zoom on Hover' effect..."
Result: The AI added polished UI micro-interactions, including a pulsing skeleton loader that displays while Mermaid.js diagrams process, and a subtle scale-on-hover effect to make the cards feel interactive and premium.
Prompt 8: "Write a lightweight JavaScript and Canvas script to create an interactive 'Particle Network' background. It should feature small, dim grey dots that slowly move and connect with thin lines... Update my card CSS to include a 'glow' effect."
Result: The AI built a custom HTML5 Canvas particle network animation that runs dynamically in the background. It also added advanced CSS effects, including floating glassmorphism cards with subtle cyan drop-shadows and backdrop-filters to create a 3D layered look.
Prompt 9: "Suggest a modern typography pairing for a tech dashboard. Use Inter or Plus Jakarta Sans for the body text to ensure high readability. Use a monospace font like JetBrains Mono or Fira Code for headings and algorithm titles..."
Result: The AI suggested and implemented a sleek, modern typography system globally. It imported Plus Jakarta Sans for highly legible body copy and JetBrains Mono for precise, technical headings.
Prompt 10: "Write a CSS global style that imports 'Inter' and 'JetBrains Mono' from Google Fonts. Set the body font to 'Inter' with line-height: 1.6. Set all headings and the '0% Mastery' text to 'JetBrains Mono' with letter-spacing: -0.02em to give it a precise, technical look"
Result: The AI globally updated the CSS to use Inter and JetBrains Mono. It optimized the line-height for readability and added negative tracking to the monospace fonts to give the text a dense, professional, and precise appearance.
Prompt 11: "include all the algorithms and all the structures mentioned in the review and give them visuals. i dont want any syntax errors and need the visuals on the first attempt"
Result: The AI read the provided study guide, extracted 21 distinct algorithms and data structures, and generated highly-accurate Mermaid.js syntax for all of them, ensuring they rendered perfectly without any syntax errors on the very first try.
Prompt 12: "include a button that gives a detailed explanation of each visual. the explanation should only pop up when i hit the button"
Result: The AI engineered an interactive pop-up modal system. It injected an "Explain Visual" button into every visual card and wrote detailed, paragraph-length explanations for all 21 algorithms, creating a clean UI that only shows information when requested by the user.
