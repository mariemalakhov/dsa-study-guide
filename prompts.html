How I Built This

A log of the AI prompts used to generate this entire website, per the assignment requirements.

Prompt 1: "Create a dashboard UI where each DSA topic has a circular progress ring showing 'Mastery %' based on correct answers, and a 'Heat Map' that turns from red to green as I complete more questions in that category. Write a JavaScript function that takes a JSON object of 50+ DSA questions and randomly selects a 'Mock Exam' of 20 questions..."
Result: The AI successfully generated a comprehensive Dashboard UI with dynamic Mastery progress rings and a Heat Map. It built out a mock exam generator in JavaScript to pull randomly from a database of categorized questions, ensuring full topic coverage, and added a 'Study Later' feature that uses Local Storage to persist weak points.
Prompt 2: "Write a CSS snippet for a subtle 'Blueprint Grid' background using background-image: linear-gradient. It should have thin, dark-grey lines on a near-black background to look like a digital engineering grid. Create a CSS/JS component that looks like a terminal window..."
Result: Antigravity overhauled the aesthetic, injecting a technical "Computer Science" theme. It created a dark-mode blueprint grid, styled the quiz containers to mimic terminal windows complete with macOS-style window controls, and utilized system fonts to emphasize the digital engineering feel.
Prompt 3: "Suggest a modern typography pairing for a tech dashboard. Use Inter or Plus Jakarta Sans for the body text to ensure high readability. Use a monospace font like JetBrains Mono or Fira Code for headings and algorithm titles..."
Result: The AI implemented a sleek, modern typography system globally. It imported Inter for highly legible body copy and JetBrains Mono for precise, technical headings. It also optimized the letter-spacing to give the text a dense, professional appearance.
Prompt 4: "include all the algorithms and all the structures mentioned in the review and give them visuals. i dont want any syntax errors and need the visuals on the first attempt"
Result: The AI read the provided study guide, extracted 21 distinct algorithms and data structures, and generated highly-accurate Mermaid.js syntax for all of them, ensuring they rendered perfectly without any syntax errors on the very first try.
Prompt 5: "include a button that gives a detailed explanation of each visual. the explanation should only pop up when i hit the button"
Result: The AI engineered an interactive pop-up modal system. It injected an "Explain Visual" button into every visual card and wrote detailed, paragraph-length explanations for all 21 algorithms, creating a clean UI that only shows information when requested by the user.
Prompt 6: "Write a lightweight JavaScript and Canvas script to create an interactive 'Particle Network' background. It should feature small, dim grey dots that slowly move and connect with thin lines... Update my card CSS to include a 'glow' effect."
Result: The AI built a custom HTML5 Canvas particle network animation that runs dynamically in the background. It also added advanced CSS effects, including floating glassmorphism cards with subtle cyan drop-shadows and backdrop-filters to create a 3D layered look.
